# AI Agent 三波浪潮

2023 年以来，AI Agent 经历了三轮范式转移。

第一波是工具调用型 Agent。大模型学会调用函数、搜索网页、执行代码，但每一步都需要人类确认。它的本质是把 LLM 当成一个"会说话的 API 网关"。

第二波是自主规划型 Agent。AutoGPT、BabyAGI 让模型自己拆解目标、选择工具、反思纠错。人类只给一句话，Agent 自己跑完全程。但成功率很低，经常陷入死循环。

第三波是**多 Agent 协作型**。不再指望一个 Agent 做所有事，而是让多个专精 Agent 组成团队——研究员负责查资料、写手负责输出、审查员负责质检。这才是真正接近"AI 员工"的方向。
